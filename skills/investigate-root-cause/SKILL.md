# Investigate Root Cause Skill

## Goal

Investigate the root cause of an incident using evidence.

## Procedure

1. Retrieve related runbooks and past postmortems.
2. Query service metrics.
3. Search service logs.
4. Check recent deployments.
5. Compare evidence timestamps.
6. Generate 2 to 3 root-cause hypotheses.

## Rules

- Do not invent evidence.
- Every hypothesis must include supporting evidence.
- Prefer recent deployment, timeout, database saturation, and resource saturation as first investigation directions.
