# Write Postmortem Skill

## Goal

Generate a structured incident postmortem draft.

## Sections

- Summary
- Impact
- Timeline
- Evidence
- Root Cause Hypotheses
- Resolution
- Follow-up Actions

## Writing Rules

1. Content must be based on existing evidence.
2. Timeline must be ordered chronologically.
3. Root cause section may include multiple hypotheses.
4. Follow-up actions should be specific and actionable.
